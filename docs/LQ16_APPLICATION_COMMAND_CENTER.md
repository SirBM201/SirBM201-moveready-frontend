# LQ16 — Guided Application Execution Command Center

## V1 acceptance contract

- Turn the highest-priority LQ15 readiness gap into a direct, vacancy-specific execution command.
- Preserve vacancy title, employer, pipeline stage, deadline urgency, evidence gap and action destination across the backend/frontend boundary.
- Deep-link a selected vacancy into the controlled application workspace.
- Show blocking, ready-to-apply, active and due-follow-up counts without implying eligibility or hiring probability.
- Keep document binding, explicit approval, employer-page handoff, manual submission confirmation and employer-evidence lifecycle updates as separate user-controlled steps.
- Never submit an application, contact an employer or infer immigration eligibility automatically.

## Production acceptance

Open a vacancy with an unresolved readiness gap and continue to Execution. Confirm that the same vacancy is selected, its title and employer are preserved, the top gap appears as the next action, and the action opens the correct evidence/profile/material destination. Resolve the gap, reconcile readiness, and confirm the command center advances without submitting anything externally.
