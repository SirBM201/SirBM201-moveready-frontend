# LQ20 — V1 Launch Acceptance and Production Hardening

LQ20 adds no product feature. It provides a read-only launch acceptance matrix for frontend fingerprint, backend health/build/auth/operations connectivity, and anonymous private-route rejection.

The probe never requests an OTP, sends credentials, mutates records, runs a vacancy scan, submits an application, contacts an employer, or performs an external action. Partial evidence is preserved when one dependency fails.

Post-V1 payments, notification delivery, provider networks, marketplaces, document storage, student expansion, travel booking, and new AI modules remain excluded.
