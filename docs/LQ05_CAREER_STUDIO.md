# LQ05 — Career Studio

## Scope

Career Studio creates structured ATS-safe résumés and cover letters with:

- contact and professional headline;
- summary;
- experience and evidence-safe achievements;
- skills;
- education;
- certifications;
- vacancy-specific cover letters;
- live preview;
- PDF and DOCX export;
- optional save to the existing private résumé vault.

## Truth policy

Exports are blocked until the user confirms that names, dates, qualifications, metrics and achievements are accurate. Profile facts may initialize the editor, but users remain responsible for confirmation. Career Studio does not invent employment outcomes, qualifications or metrics.

## Storage

The current working draft is saved in browser storage for recovery on the same device. Approved generated PDF or DOCX files can be stored in the existing authenticated résumé vault, where normal versioning, active/archive controls and temporary downloads continue to apply.

A browser draft is convenience state—not the permanent account record.

## Output policy

- PDF is generated as selectable text with automatic page breaks.
- DOCX is a standards-based Office Open XML package using an ATS-safe Arial style.
- Both formats use a single-column layout without text boxes, icons, tables or images.
- The live preview is intentionally close to, but not a pixel guarantee of, Office/PDF rendering.

## Manual acceptance

1. Create a multi-page résumé and export PDF and DOCX.
2. Open DOCX in Microsoft Word or LibreOffice.
3. Confirm headings, bullets, page margins and special characters.
4. Save both formats to the vault and download them again.
5. Create a cover letter and repeat both exports.
6. Complete editor and export at 375px width and by keyboard.
7. Confirm export is blocked when the truth confirmation is unchecked.
