# V1 Cross-Engine Orchestration

## Canonical opportunity card
Each opportunity card should use a common presentation contract:
- title / country / category
- why recommended
- Opportunity Fit
- Eligibility/Readiness
- Financial Readiness when applicable
- Career Match + Application Viability for jobs
- top blocker
- next best action
- provenance + last rule check
- save / compare / continue

Unknown information is shown as `Needs assessment`, not scored as zero and not guessed.

## Next-best-action priority
1. Hard blocker: legal/eligibility/work-authorization restriction.
2. Expiring or imminent deadline.
3. Missing mandatory document/evidence.
4. Financial shortfall against a known requirement.
5. Language/exam gap tied to the selected goal.
6. Career/CV/skills gap.
7. Optimization opportunity.

Only one action is designated `Next best action`; secondary actions remain visible.

## Engine hand-offs
Opportunity Finder → Jobs when employment is the best route.
Opportunity Finder → Language Coach when a language score is a material blocker.
Opportunity Finder → Financial Readiness when funds are material.
Opportunity Finder → Documents when evidence is missing.
Jobs → CV/cover letter only after application viability is acceptable or explicitly acknowledged.
Jobs → Language Coach when language materially affects the target role/pathway.
Language Coach → Opportunity when target score/readiness materially improves.
Financial Readiness → Opportunity when target funds are met or requirement changes.
Documents → Applications when mandatory checklist is sufficiently complete.
Applications → Settlement after positive outcome/arrival planning.
Settlement → Jobs/Growth after arrival.

## Local vs international jobs
LOCAL: emphasize role fit, commute/location, career progression, compensation where available. Suppress sponsorship clutter unless genuinely relevant.
INTERNATIONAL: always consider authorization/sponsorship evidence before high-priority recommendation.
BOTH: present local and international opportunities clearly labeled and rank by realistic application priority, not raw skills score alone.

## Language recommendation behavior
The engine may recommend English, French or a balance based on the user's goals, but never silently changes the user's learning choice. Both-language allocations support 50/50, 70/30 and 30/70.

## Provenance
Rules that can materially change eligibility, required funds, work rights or deadlines require official-source metadata and a checked/updated date. User-entered assumptions are labeled separately. MoveReady analysis must remain distinguishable from source facts.
