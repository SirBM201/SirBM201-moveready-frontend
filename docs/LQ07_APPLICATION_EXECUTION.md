# LQ07 — Application execution and portfolio integration

## Controlled sequence

1. Select a recorded vacancy.
2. Reconcile B19 readiness.
3. Bind an active CV and optional cover letter from the private vault.
4. Confirm official requirements and employer-question readiness.
5. Mark ready only after blockers are resolved.
6. Create a truthful draft package.
7. Review, then explicitly approve the package.
8. Prepare a handoff; MoveReady does not submit it.
9. Open the external employer destination.
10. Confirm manual submission only after the user submits.
11. Create the evidence-bound application lifecycle.
12. Record employer status changes with user confirmation.
13. Schedule and complete follow-ups; MoveReady never contacts the employer automatically.
14. Use the portfolio next-action feed and safe reconciliation.

## Safety rules

- No automatic submission or employer contact.
- Stale drafts cannot be approved.
- A handoff requires an approved draft.
- Submission confirmation is a distinct user action.
- Lifecycle changes require employer evidence and user confirmation.
- Terminal states cannot silently reopen.
- Portfolio reconciliation performs only explicitly validated corrective operations.

## Manual acceptance

Run one complete vacancy through readiness → material binding → ready → draft → reviewed → approved → handoff → opened → manual submission → lifecycle → follow-up. Confirm every invalid early transition fails safely and all controls remain usable at 375px width.
