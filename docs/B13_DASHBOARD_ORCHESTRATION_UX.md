# B13 dashboard orchestration UX

The account dashboard now leads with one backend-ranked next action and a compact FIND → QUALIFY → MOVE view:

- FIND: Jobs and Route Finder.
- QUALIFY: Passport, Language, and Financial Readiness.
- MOVE: Documents and Applications.

Detailed totals, secondary tools, account controls, and safety explanations remain available through progressive disclosure. The dashboard refuses to treat any Action Center response older than `b13-v1` as current.

No engine result is presented as an approval or guarantee. The UI keeps unknown information as needs assessment and links users back to the underlying workspace before they act.
