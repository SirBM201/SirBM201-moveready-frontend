# LQ06 — Vacancy Alignment Report

## Score composition

| Component | Maximum |
|---|---:|
| Skills alignment | 40 |
| Responsibilities and qualifications | 25 |
| Title and seniority alignment | 15 |
| Achievement evidence | 10 |
| Structure and readability | 10 |

The score is deterministic and explainable. It is not an ATS pass probability, hiring prediction or outcome guarantee.

## Evidence rules

- A listed skill and an achievement-supported skill are different states.
- Missing vacancy descriptions or structured skills remain unknown.
- Keywords without context do not receive achievement-evidence credit.
- Metrics count only when the user has recorded them and confirmed their truth.
- Work-rights and sponsorship blockers remain outside résumé alignment and cannot be overridden by similarity.

## Before and potential-after

The “potential after improvements” number uses only part of the recoverable component gap. It helps prioritize editing; it is not a promised future score or employer outcome. Users must add only facts they can support.

## Manual acceptance

1. Test a vacancy with structured skills and description.
2. Test one missing both fields and confirm unknown treatment.
3. Test existing-work-authorization-required and unverified-sponsorship cases.
4. Add a skill without achievement evidence and confirm “mentioned only.”
5. Add a supported achievement and confirm “matched with evidence.”
6. Confirm mobile and keyboard completion.
7. Verify the report links back to Career Studio and the vacancy source.
